# GitHub Classroom

_Goal: Use GitHub Classroom for the exam simulation as it will be for the real exam._

As reported in the exam rules, you will use GitHub Classroom to submit your web application for the evaluation. To avoid last-minute issues, during this exam simulation you will be able to verify that you can successfully use the GitHub Classroom platform.

NOTE: the application submitted for the exam simulation will not be NOT evaluated in any way. It is just a way for you to become familiar with the system.

## Basic requirements

The basic requirement is having a personal GitHub account, and being familiar with git commands.

## Getting the skeleton project

The skeleton project will be distributed as a “Classroom Link”, that will give you access to a Classroom Assignment.

## First login

At the first login on GitHub Classroom you have to associate your GitHub user to the student’s ID as detailed below. This is needed only once.

  1. Authorize your GitHub user to access the Classroom platform.
  2. Associate your account with your student identity, by selecting your name from the full list of students.

NOTE: If your name is not on the list, please tell the teachers. Be careful in selecting the correct student identity.

## Accepting the assignement

For every new exam, you must “accept the assignment” to get a copy of the skeleton repository.

  1. Accept the proposed assignment using the link specific to the exam or (simulation)[https://classroom.github.com/a/Rdp8J0RZ].
  2. Classroom will create a new private repository and will fork a copy of the skeleton.
  3. After creation, you get a link to the repository in which YOU must work. The link contains a common part (the exam info), concatenated with your GitHub username.
  4. Now you have your repository and may freely work on it. The repository is private, and only you and the teachers may access it.

## Developing the project

You may create or use different branches, but the final project must lie in the main branch (the content of other branches will not be considered). The last commit (when you submit the exam, before the deadline), must be tagged with ‘final’. We will assume that, if you don’t push a commit tagged with final, you decided not to take the exam. No further commits should be made to the repository, until after the oral discussion.
